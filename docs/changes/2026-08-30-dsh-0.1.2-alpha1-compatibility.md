# 0.4.3 — DSH 0.1.2-alpha.1 compatibility record

## Upstream breaking changes

- `@deepseek-ai/dsh-client-runtime` and `connection.api.sessions` no longer exist.
- Session snapshots describe lifecycle state; rendered messages and node order live in the `uiConversation` Chat target.
- Model routing is exposed through each Session's `modelSelection` projection.
- `MarkdownText` requires the alpha.1 labels shape, and injected services are scoped to the declaring Cordis context.

## Sidechat changes

- Use `api-session-controller` and `api-workspace-controller` for parent/child lifecycle operations.
- Read transcripts from `uiConversation.binding(sessionId).target("chat")` and model routes from native `modelSelection`.
- Pass the injected root runtime into Better Sidebar tabs instead of reading unavailable services from the tab child context.
- Provide the alpha.1 Markdown labels contract.
- Preserve Manager model hot loading: mounted Sidechat instances switch at the next request boundary without cancelling an active answer.
- Keep Annotation Core and Better Sidebar integration capability-driven through optional `*` peers.
- Build the mount-test Annotation Core provider from its current `main` branch instead of reinstalling it as a Sidechat dependency; exercise the official `dsh-v0.1.2-alpha.1` source tag with Better Sidebar `0.17.1`, because the Alpha.1 CLI is not published on npm.

No RC2 runtime adapter is retained. Compatibility is established by the exercised alpha.1 interfaces and regression tests.
