# DSH-SIDECHAT-20260822-001: 将本地维护历史迁移到独立 Git 仓库

## 现象

将本地维护历史迁移到独立 Git 仓库

## 根因

原本的本地修改与另外两个插件共享 `D:\AI\Deepseek-Harness-EAC\Plugin` 仓库。单个插件无法独立建立兼容分支、标签或回退，因而不满足维护引擎的独立仓库约束。

## 影响范围

仅改变 `dsh-sidechat` 的源码维护入口和 Git 元数据。EAC profile 仍引用原有 `dsh-sidechat-0.1.0-codex.2.tgz`，没有切换运行插件。

## 修改内容

使用 `git subtree split --prefix=dsh-sidechat` 从旧 monorepo 保留路径历史，建立新仓库 `D:\AI\DSH-Plugin-Repositories\dsh-sidechat`。保留 3 个原提交，并登记为 `forked/Tier 1`，upstream 为 `https://github.com/g-yixuan/dsh-sidechat.git`。

## 验证结果

拆分前旧目录 tree 与新仓库初始 HEAD tree 均为 `2d389ad846d2fa814fc853c84711cf8766e780b1`。`pnpm test` 的 65 项测试通过，`pnpm build` 通过且工作树无生成差异。

## 回退方法

旧 monorepo、原 tgz 和 profile 声明均保留。若新仓库后续出现问题，停止使用新仓库并继续从旧 monorepo 构建即可；不需要修改当前 EAC。

## 用户数据影响

无。迁移和验证不读取或修改会话、工作区、附件、密钥以及 EAC 用户设置。
