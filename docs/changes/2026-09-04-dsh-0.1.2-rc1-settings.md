# Sidechat 0.4.5 - DSH 0.1.2-rc.1 Settings lifecycle

This release starts from the complete 0.4.4 Alpha2 settings implementation at
Git commit `8fbb6e02a284d8e366c48d29317d9ddf092840c4`; it does not overwrite those
features with the older 0.4.3 branch.

DSH 0.1.2-rc.1 exposes the consumer lifecycle through
`SettingsProvider.installSection()`. Sidechat now delegates Settings attach,
watch, detach, and fallback ownership to that public provider contract instead
of duplicating the provider's fiber-state bookkeeping.

The Manager model selector remains live: saving a route updates every mounted
Sidechat, an in-flight answer is not cancelled, and the next request uses the
new route. Fork, hidden archive, restore, Annotation Core capability
negotiation, and optional Better Sidebar integration are unchanged. No older
DSH Settings compatibility path is retained.
