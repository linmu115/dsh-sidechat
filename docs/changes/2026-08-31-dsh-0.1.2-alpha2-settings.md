# Sidechat 0.4.4 — DSH 0.1.2-alpha.2 Settings migration

DSH 0.1.2-alpha.2 stopped exporting the runtime helpers `settingsNamespace()`
and `installSettingsSection()` from `@deepseek-ai/dsh-settings`. Sidechat now
passes its literal `dsh-sidechat` namespace directly to the public
`ctx.settings.register()` service and owns the attach, watch, detach, and
fallback lifecycle locally.

The Manager model selector keeps the existing live behavior: a saved model
route updates every open Sidechat immediately, while an in-flight answer is
left intact and the next request uses the new route. Development dependencies
now target the npm-published Alpha.2 packages so this contract is typechecked
against the runtime that consumes it.
